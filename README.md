**calamus** is a [Typst](https://typst.app/) template for SOČ (Stredoškolská odborná činnosť) theses, designed for **Gymnázium Karola Štúra, Námestie slobody 5, Modra**.

The template is based on the [official SOČ methodology](https://archiv.siov.sk/wp-content/uploads/2019/06/Metodika_SOC_2019_B5.pdf).
